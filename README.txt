APP ESTOQUE — 23 MÓDULOS

Esta versão é um aplicativo web instalável (PWA) para iPhone/iPad.
- 23 módulos
- 3 posições por módulo: Cima, Meio e Baixo
- Pesquisa por produto
- Adicionar, editar e localizar produtos
- Quantidades e observações
- Dados salvos no navegador do aparelho

IMPORTANTE:
Para instalar no iPhone como aplicativo, os arquivos precisam estar publicados em um endereço HTTPS.
Uma opção gratuita é usar GitHub Pages.
No iPhone, abra o endereço no Safari > Compartilhar > Adicionar à Tela de Início.

Os dados ficam no aparelho/navegador nesta primeira versão. Para compartilhar o mesmo estoque entre vários funcionários, será necessário uma versão com banco de dados online.
